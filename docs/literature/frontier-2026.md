## A. GEPA 之后的 prompt 优化直接后继（2025Q3–2026-09）

### A0. 基准状态更新（重要事实）
- **GEPA 已被 ICLR 2026 接收为 Oral**：[arXiv:2507.19457v2](https://arxiv.org/abs/2507.19457)（v2 更新 2026-02-14，comment："Accepted to ICLR 2026 (Oral)"，代码 https://github.com/gepa-ai/gepa ）。**含义**：APC 对比对象从预印本升级为正式 Oral；审稿人以"GEPA 后继"视角看 APC 是默认动作，F7 的 GEPA 复现（+.0024 噪声带内）从加分项变成必交作业。
- **GEPA 作者团队自己的后继**：**FST《Learning, Fast and Slow: Towards LLMs That Adapt Continually》** [arXiv:2605.12484](https://arxiv.org/abs/2605.12484)（2026-05-12，v2 05-14；Agrawal/Gonzalez/Zaharia/Keutzer/Dhillon/Agarwal 等，含 GEPA 一作）——"优化后的上下文 = fast weights、参数 = slow weights"，样本效率较纯 RL 提升 3×、KL 漂移少 70%、持续学习不卡壳（博客 gepa-ai.github.io/gepa/blog/2026-05-11/）。与 APC："编译产物作为可替换快通路"叙事部分重叠——APC 的差异须落在 genome 的离散性与画像驱动，而非"上下文是可学参数"。必引。

### A1. 结构化 / 分段 / 类型化表征阵营（APC genome 主张的最近邻，必比）
1. **SEPO：Evidence-Grounded Prompt Optimization via Structural Editing** [arXiv:2608.28067](https://arxiv.org/abs/2608.28067)（2026-08-28）——不再整段重写 prompt：在**两层 prompt schema 上对稳定的、有类型的单元做局部编辑**，维护"edit-effect lineage"（每次编辑 ↔ 新修复/新破坏的样例）反馈后续搜索；14 任务超 GEPA +3.1pp（Llama-3.1-8B）/+2.2pp（Qwen3-8B），优化 token 2.9M vs 4.1M，产物短 5×。与 APC：**结构化通路已被抢占**——SEPO 是"typed units + 局部编辑 + 效应归因"，APC 剩存的差异化 = 类型化**基因位点全集**（结构即搜索空间而非编辑对象）+ ModelProfile 先验 + 跨任务零损耗迁移证据；若不引不比 SEPO，novelty 主张会被审稿人直接击穿。必比（与 GEPA 同列头牌基线）。
2. **SAPO：From Monolithic to Modular — Segment-level APO** [arXiv:2608.11219](https://arxiv.org/abs/2608.11219)（2026-07-21，IJCAI-ECAI 2026 RobustifAI workshop）——把 prompt 分解为 role/context/tasks/output-format 四段并按 top/bottom-5 样例逐段诊断改进；对 APE/OPRO/EvoPrompt/GEPA/StraGO 平均最优。与 APC：分段结构已是 workshop 级共识；APC 的 segment≈genome 的粗粒度前传，引用以证"结构载体"趋势、并用画像编译与 SHA 划界。必引。
3. **PCO：Prompt Codebooks — Discrete Compositional Optimization** [arXiv:2605.28360](https://arxiv.org/abs/2605.28360)（2026-05-27，v2 2026-08-03）——APO 重构为**有限自然语言"instinct"词表上的离散组合学习**，LLM-encoder 按输入路由码本条目、generator 组装、critic 输出按变量分解的文本梯度，min-max 联合训练；超 GEPA（HotpotQA +6.34pp）、部署 prompt 比 GEPA 短 3×。与 APC：同为"离散组合结构"，差异在 PCO 是 instance 级路由 + 学习码本，APC 是 task 级 genome + 画像规则先验 + 进化搜索。必引必比（若预算允许至少入 related work 表格）。
4. **Control-Data Flow Separation：Stable Prompt Optimization in Multi-Agent LLMs** [arXiv:2609.00621](https://arxiv.org/abs/2609.00621)（2026-09-01，**EMNLP 2026 Findings**，journal_ref 标注；Yuntian Deng 组）——优化中 prompt 的双重身份（内容生成 vs 执行协议）互相污染：面向内容的编辑会腐蚀路由/终止协议使管线整体崩；解法=控制流编译为**有类型、经校验的程序对象**，自然语言只留在可优化数据流侧；三场景 100% 协议有效性。与 APC：为"硬结构出语言、语言进可搜索槽位"的分层世界观提供 2026 正式发表的最新佐证（与 2608.02639 的编译价值、Sclar 格式敏感性构成三角），但无搜索、无画像。必引（§1/§2 世界观段）。
5. **TARA：Type-Aware Repair Allocation（T2I）** [arXiv:2607.18724](https://arxiv.org/abs/2607.18724)（2026-07-21）——把语义 prompt 优化形式化为**原子修复分配**：每条失败命题路由到类型条件修复算子，再"compiled into one executable prompt"；含 **semantic repair gate（accept-or-revert，单次只允许一个规定修复）**防语义回归。与 APC：域不同（T2I）但"分派→编译→门控"三段式与 Compile-as-Hypothesis + AutoAPC 同构，是门控家族的自然语言侧最近邻。必引。

### A2. GEPA 病理诊断阵营（反思通路的失效与补救——F7 null 结果的外围佐证群）
6. **ESPO：Error-Structured Prompt Optimization** [arXiv:2609.04197](https://arxiv.org/abs/2609.04197)（2026-09-03，**EMNLP 2026 main**，AWS 系作者）——点名 GEPA：**prompt bloat（规则只加不减、3× 长而精度不涨）**，根因=错误观察不完整 + 多样性不足 + **选择不可靠**；对策=Diagnose（一轮聚类全部错误）/Propose（4 独立偏置策略）/**Select（bootstrap stability selection）**；7 基准 +3.76pp 于 GEPA、prompt 短 47%，且消融显示"加多样性不做 bootstrap 选择反而 −1.20%"。与 APC：F7 反思通路同归于平的 regime 观察得到独立复证（选择稳定性是胜负手）；其 bootstrap 重采样稳定选择 = AutoAPC 噪声带的最近竞品方法（差异见 D-3）。**必比（当前公开最强 GEPA 后继，EMNLP main）**。
7. **NPO：Naive Prompt Optimization — Rethinking the Need for Complex Prompt Search** [arXiv:2608.27266](https://arxiv.org/abs/2608.27266)（2026-08-27）——teacher 模型 + rollout 反馈的**单谱系线性迭代**即打平/超过 GEPA 且更省 rollout，teacher 越强越不需要复杂搜索；NPO 产物**逐字跨学生模型迁移**（同家族尤佳）。与 APC：双刃——一边为"搜索复杂度不是增益来源"提供怀疑论弹药（须正面回应：APC 的 genome 价值主张是可审计/可迁移/可门控，不是更大搜索），一边其 verbatim 跨模型迁移与 APC transfer-0 互证。必引必谈。
8. **MAGE：Multi-component Prompt Optimization 的稳定性-性能权衡** [arXiv:2607.11944](https://arxiv.org/abs/2607.11944)（2026-07-11）——受控消融发现 **Prompt Optimization Coupling Effect（POCE）**：多条随机信号进入同一闭环反思回路时性能与方差同时上升（候选池 n=3→5 平均 +21.6% 但方差 ×3.7），且不可由单组件行为预测；failure-grounded 反思是必要条件（纯分数 OPRO / 抽象批评 Self-Refine 不涨）；**低数据（Ntrain=30）固定好 prompt 胜过一切反思优化器**；结论句式："prompt 优化系统是耦合随机过程，评测必须同时报性能与稳定性"。与 APC：C 节主锚点 + 配对同日复测协议的最强同方向论者（他们要"报方差"，APC 更进一步"同日控制消除它"）。必引必比（稳定性叙事框架）。
9. **p1：Better Prompt Optimization with Fewer Prompts** [arXiv:2604.08801](https://arxiv.org/abs/2604.08801)（2026-04-09，v2 2026-08-26；Joachims/Brantley/Wen Sun 组）——把 APO 的 reward 方差**分解为响应间方差（生成随机性）与系统 prompt 间方差（候选质量差）**：前者主导时优化必然失败；用户 prompt 越多样、扩数据反而压低 prompt 间方差、有害；解法=挑高判别力的小子集（AIME24 仅 2 题即可训出泛型 system prompt），超 GEPA。与 APC：给 F7 的"强模型+高判分覆盖 ⇒ 组间方差消失 ⇒ 一切优化器打平"提供现成的理论语言，讨论节直接借用其分解记号。必引。
10. **DIVE：Diversity-Driven Skill Evolution** [arXiv:2608.12486](https://arxiv.org/abs/2608.12486)（2026-08-12，IBM Payani 系）——冻结模型进化"自然语言技能"（无 teacher）；明确点名"单轨迹进化会过拟合采样经验或收敛次优 = **optimization variance**"，以 bootstrap 经验上的多群体独立进化 + 互补集联合选择压制之；少于 SFT/GRPO/GEPA 的 rollout 取得更大增益，技能跨规模跨家族迁移（GPT-5-nano 达 GPT-5 水平）。与 APC：多样群体=搜索侧方差控制，与 APC 配对同日复测=测量侧方差控制，构成互补两条轴（可写入 §讨论）。必引。
11. **To Write or to Automate, That Is the Question** [arXiv:2603.25169](https://arxiv.org/abs/2603.25169)（2026-03-26，v2 2026-05-05，EAMT 2026 投稿）——翻译/术语插入/LQA 五模型配置：专家手写 prompt 与 GEPA-优化 prompt 多数对比**统计不可分**，LQA 上专家更强。与 APC："反思增益可能本就浅"的又一独立复证，F7 null 的语境化引用。必引。
12. **Beyond the Answer: Decoding the Behavior of LLMs as Scientific Reasoners** [arXiv:2603.28038](https://arxiv.org/abs/2603.28038)（2026-03-30，**ICLR 2026 Post-AGI ws**）——GEPA 优化 prompt 的科学推理增益常来自**模型特有"local logic"启发式，跨系统不泛化且脆弱**。与 APC：反思产物的过拟合画像——APC 的 genome+画像恰恰把"模型特异性"显式对象化（对峙性引用：他们批评隐式过拟合，APC 主张显式建模）。必引。

### A3. 反思通路变体（对比式反思 2026 潮）
13. **CORE：Contrastive Reflection Enables Rapid Improvements in Reasoning** [arXiv:2605.28742](https://arxiv.org/abs/2605.28742)（2026-05-27，v2 06-05；Noah Goodman/Judith Fan 组，Stanford）——对比成功/失败推理轨迹蒸馏"insights"（策略与约束的自然语言描述），5 个训练样本即起步，改进速度胜 GRPO/GEPA/episodic RAG/MemRL 且更省上下文。与 APC：与 GEPA 单轨迹诊断相对——APC 若强调"结构化归因"，CORE 是自由文本对比路的最新标杆。必引。
14. **ContraPrompt：Dyadic Reasoning Trace Analysis** [arXiv:2604.17937](https://arxiv.org/abs/2604.17937)（2026-04-20）——同一输入"失败→反馈重试成功"两链 CoT 差分=优化信号（dyadic contrast），提取规则组织成**输入感知决策树**；4 基准全面超 GEPA（HotpotQA +8.29pp），53 题黑盒优化 11 胜 41 平 1 负。与 APC："规则树"与 genome 规则最近邻（但规则源自轨迹对比而非画像先验，且树只作用于指令路由）；消融显示对比性是命门（去除 −16% 相对）。必引，注意差异化表述。
15. **Contrastive Reflection for Iterative Prompt Optimization（agentic IR）** [arXiv:2606.30840](https://arxiv.org/abs/2606.30840)（2026-06-29，KDD 2026 Agent4IR ws）——错误锚定行为切片 + 邻近成功案例对比 → teacher 定向编辑；**编辑仅当验证集提升才接受，且可选回归检查**；HotpotQA EM 51.4→60.4（MIPROv2 59.4、GEPA 57.0）。与 APC：gate-accept 家族又一成员（与 AutoAPC 差异：其验证比较非同日配对、无噪声带概念）。必引。
16. **CMVF：Are Prompt Optimizers Blind? Cross-Modal Visual Feedback** [arXiv:2607.24354](https://arxiv.org/abs/2607.24354)（2026-07-27）——VLM 域 APO 的**反馈通道盲区**：优化器读题读答案却不读失败图像，无法诊断视觉接地错误；补上失败条件化视觉诊断 + 错误感知聚合后 12 VQA × 4 VLM 平均 +2.4 全面第一。与 APC："反思通路的输入决定优化上限"——APC 的 TrialResult/归因链正是结构化反馈通道，可借其论证。必引（§2 反馈设计）。
17. **OmniPrompt / OmniPhys** [arXiv:2607.25641](https://arxiv.org/abs/2607.25641)（2026-07-28，**KDD 2026 DB track**）——高随机生成导致"**gradient hallucination**"：优化器被瞬时伪影而非系统性缺陷误导；对策=每查询 K 样本反馈缓冲 + 批间合并后才更新 meta-policy（滤种子/查询局部噪声），另设双路验证协议。与 APC：把"先降噪再更新"用于 T2I，其"feedback buffer 降噪"与 APC"配对同日复测"同属噪声治理，域不同。必引。

### A4. 搜索策略自动化 / 归因 / 预算（与 SHA、编译器地位相关）
18. **RLMOpt：Adaptive Prompt Optimization via Recursive Language Models** [arXiv:2608.10471](https://arxiv.org/abs/2608.10471)（2026-08-11）——**搜索策略本身交给 RLM agent**（读任务、分析失败、分配评估预算、决定停机），外围**确定性 harness 强制客观评分、Pareto 选择、回归约束**；11 组 matched benchmark-seed 对比 9 胜 GEPA；**11 次运行从未产出劣于种子的 prompt，而 GEPA 两次跌破起点**；核心经验结论：**增益主要由种子 prompt 的 headroom 决定而非搜索预算**。与 APC：(i) seed-headroom 是 rule-root 双峰发现的直接先行概念（C 节必引）；(ii) "LLM 提议 + 确定性 harness 门控"结构上就是 AutoAPC 的 agentic 化版本，划界要写清（harness 细节未公布[未核实]）。
19. **FAPO：Fully Automated Prompt Optimization of Multi-Step LLM Pipelines** [arXiv:2606.19605](https://arxiv.org/abs/2606.19605)（2026-06-17，v2 06-20；Yale/Karbasi 系）——让 Claude Code 在标准化代码库内**先 prompt 编辑、归因指出结构瓶颈才升级改链结构**，反复验证变体；18 组对 GEPA 15 胜（平均 +14.1pp），结构升级的 6 组全胜（+33.8pp），安全任务 CTIBench-RCM 亦正。与 APC："coding agent 兜底一切管线优化"路线对"专用编译器"的存在合法性构成修辞压力；应对=引用并强调画像先验、可审计 genome 与零成本门控是 agent 循环不具备的。必引必谈。
20. **AgentGrad：Intervention-guided Prompt Optimization for Multi-Agent Systems** [arXiv:2609.08572](https://arxiv.org/abs/2609.08572)（2026-09-08）——文本梯度法两阶段缺陷（梯度提取不验证"改这个 prompt 是否真能解决失败"；梯度聚合随机拼接混淆失败模式）；对策=**序贯干预定位责任 agent**（agent 级监督）+ 语义梯度抽象（聚类归并成一般化修正模式）；5 MAS 基准 SOTA、优化墙钟 ×2.5 加速。与 APC："先归因再编辑"与 APC TrialResult 归因链同路。必引（反思通路簇）。
21. **LEVI：Stronger Search Architectures Can Substitute for Larger LLMs** [arXiv:2605.09764](https://arxiv.org/abs/2605.09764)（2026-05-10，开源 github.com/ttanv/levi）——harness-first 进化框架：多样性 archive 全程维护 + **大小模型混合 mutation router** + rank-preserving proxy 基准；prompt 优化 <½ GEPA rollout 打平或超过，系统研究发现任务 35× 降本。与 APC：预算侧（SHA 相邻）最新对照物；"archive 多样性↔DIVE 群体↔APC Pareto/genome 多样性"可归段。必引（预算段）。
22. **ExTS：Exploit More, Explore Smarter for Budget-Constrained Agentic Search** [arXiv:2608.23848](https://arxiv.org/abs/2608.23848)（2026-08-24）——小评估预算下 MCTS 预算错配的三机制修复：判别式 reward shaping（窄分数分布下分离候选）、虚拟子节点估计"开新分支价值"、质量条件分支。与 APC：SHA/rollout 货币化的同期工作，窄分数分布问题=APC 噪声带问题的搜索侧镜像。必引（预算段，可选）。
23. **SSO：Self-Supervised Skill Optimization** [arXiv:2607.28777](https://arxiv.org/abs/2607.28777)（2026-07-30）——无 GT 场景：judge 比较成对执行 + 行为差异提取 + 跨实例证据聚合排序，**新 skill 仅当在无标签验证集上更好才接受**；超越现有 GT-free 优化器、逼近 GT-based 最强。与 APC：接受门控在无标签下的替代实现（AutoAPC 假设有 val 分数可用——写作时明确适用域）。必引（门控家族）。

### A5. 选择 / 多目标 / 联合配置（AutoAPC 的理论对手群 + 会议清单素材）
24. **Efficient Multi-objective Prompt Optimization via Pure-exploration Bandits** [arXiv:2605.14553](https://arxiv.org/abs/2605.14553)（2026-05-14，**ICLR 2026 main，已核实 comment："Published as a conference paper at ICLR 2026"**）——多目标 prompt 选择的两个问题：**Pareto prompt 集恢复 & best-feasible prompt 识别**，纯探索 bandit 框架 + 线性情形识别误差理论保证。与 APC：AutoAPC 的形式化理论对应物（差异：他们要采样预算、APC 吃免费的同日 val 分数）——D-3 必引头名。必比（若审稿人问"为什么不用 bandit"，此即答案）。
25. **PDO：LLM Prompt Duel Optimizer（label-free dueling bandit）** [arXiv:2510.13907v3](https://arxiv.org/abs/2510.13907)（首发 2025-10-14，**ACL 2026 Findings**，camera-ready 2026-04）——judge 成对偏好 + Double Thompson Sampling 在固定比较预算下选信息量最大的对比 + top-performer 引导变异；BBH/MS MARCO 省标签超 label-free 基线。与 APC：候选选择另一族（比较反馈 vs 绝对分+噪声带）。必引（选择段）。
26. **COMPAS：Difficulty-Aware Joint Search（模型×prompt×解码设置）** [arXiv:2608.04336](https://arxiv.org/abs/2608.04336)（2026-08-05，代码+复现产物 https://github.com/gjz78910/COMPAS ）——实证三点：prompt 与解码设置交互、**调参效果因模型而异**、最优配置随任务难度变；离线学"分组质量-成本前沿"再在线路由；LiveCodeBench pass@1 45.9→52.8 且成本 $36.57→$4.92，SWE-bench 76.0 vs 70.0。与 APC："tuning effects vary by model"=ModelProfile 前提的又一独立实证（与 2608.02639、FLASK 并列三连引）。必引。

## B. 推理模型评测可靠性：temp=0 非确定性、跨日漂移与"配对同日复测"是否已被提出

### B1. temp=0 非确定性的定量文献（已确立事实，不可再当发现卖）
- **《Non-Determinism of "Deterministic" LLM Settings》** [arXiv:2408.04667v5](https://arxiv.org/abs/2408.04667)（首发 2024-08，v5 2025-04-02）——5 模型 × 8 任务 × 10 重复：同配置准确率波动最高 **15%**、最好最坏差 **70%**；提 TARr@N/TARa@N 度量；代码 https://github.com/breckbaldwin/llm-stability 。
- **Thinking Machines Lab《Defeating Nondeterminism in LLM Inference》**（2025-09，https://thinkingmachines.ai/blog/defeating-nondeterminism-in-llm-inference/ ）——根因=批组成相关的浮点归约顺序；开源 vLLM batch-invariance 修复。**工业界事实标准，2026 引用惯例已成型**（经 web 检索 2026-09-09 证实）。
- **《Necessary but Not Sufficient: Temperature Control and Reproducibility in LLM-as-Judge Safety Evaluations》** [arXiv:2606.26185](https://arxiv.org/abs/2606.26185)（2026-06-24，日本 AISI 语境）——生产判分 harness 忘设 temperature 时 provider 默认 1.0：边界题 20 次重跑逐题翻转率最高 ~50%；**钉死 temp=0（甚至 top_k=1）后仍有边界项不可复现**（690 调用×2 provider×3 档×5 配置）；并记录 Claude Opus 4.7/4.8 **已删除 temperature 参数**这一代际变化；结论句："单 run 判分不报方差/分歧率＝把噪声当安全属性"，建议把 **grader disagreement 当一等健康指标**。
- **《Dissecting Non-Determinism in Large Language Models》** ICLR 2026 blog posts：https://iclr-blogposts.github.io/2026/blog/2026/dissecting-non-determinism/ （2026；具体发表日[未核实]）。
- 辅证：《Beyond Accuracy: LLM Variability in Evidence Screening》 [arXiv:2604.27006](https://arxiv.org/abs/2604.27006)（2026-04-29，12 模型仍见 temp=0 残余非确定性）；《Evaluation of LLM-Based SE Tools》 [arXiv:2604.24621](https://arxiv.org/abs/2604.24621)（EASE 2026，把"非确定性导致的评测不稳定"列为核心挑战）；《Dataset-Level Metrics Attenuate Non-Determinism》 [arXiv:2604.13413](https://arxiv.org/abs/2604.13413)（2026-04-15，扩散 LM；聚合指标系统性**衰减**非确定性 + FVA 因子方差分解——与 APC "样本级翻转被聚合掩盖"同观察）。

### B2. 跨日漂移 / 静默更新（APC Δ.028 的社区语境）
- **《Randomness in LLMs: What researchers need to know (and report)》** [arXiv:2607.24372](https://arxiv.org/abs/2607.24372)（2026-07-27，econ.GN，六作者含 CSE 主编级人）——随机源四分类（有意采样/静默模型更新/浮点舍入/MoE 路由），temp=0 只灭第一种；**给出期刊/复现包的报告标准：LLM 输出是分布抽样而非固定测量**。→ APC 引用惯例的学术化落点。
- **《Silent Updates: Measuring and Closing the Post-Deployment Disclosure Gap》** [arXiv:2608.11803](https://arxiv.org/abs/2608.11803)（2026-08-12，**AIES-26**）——9 家一方 API + 7 家推理托管抽样：**无一提供可验证"评测所用工件＝当下服务工件"的 chain of custody**；提出 Silent Updates Scorecard 与披露触发制度。→ "跨日漂移"的制度性根因证明。
- **《Test Before You Deploy: Governing Updates in the LLM Supply Chain》** [arXiv:2604.27789](https://arxiv.org/abs/2604.27789)（2026-04-30，FSE 2026 LLMSC ws，DOI 10.1145/3803437.3805535 已核实）——部署侧生产合同 + 风险分类测试 + **兼容性门**治理静默更新回归。
- **《Opaque Epistemic Mediation》** [arXiv:2607.22513](https://arxiv.org/abs/2607.22513)（2026-07-24）——**一夜之间**静默补丁反转 Grok 输出；同模型 ID API 端 75 分 vs web 端三个月后 5.5 分。→ 漂移幅度可以远超 ±0.03 的极端案例（APC 的 Δ.028 是温和版，引用防"你们的漂移好小"质疑）。
- **《EPC: A Standardized Protocol for Measuring Evaluator Preference Dynamics》** [arXiv:2607.00297](https://arxiv.org/abs/2607.00297)（2026-07-01）——RFC 式协议 + **版本化参考快照**：N=122 重复、注明模型版本/API 端点/**测量日期**，明示"所有数值随专有评测器静默更新而衰减"。→ 与 APC 最接近的"时间戳测量"正式协议，但其复测非同日配对设计。
- 近邻术语占用：《GenEval 2: Addressing Benchmark Drift》 [arXiv:2512.16853](https://arxiv.org/abs/2512.16853)（2025-12-18）用 benchmark drift 指**判分器标准落后人类**（≠日漂移）；《Scientific judgment drifts over time in AI ideation》 [arXiv:2511.04964](https://arxiv.org/abs/2511.04964)（2025-11-07，v2 2026-03-24）测**人类评委** test-retest ICC 0.59–0.74 并明确倡议 "**drift-aware evaluation protocols** and longitudinal benchmarks"——该措辞已被占用（人侧），APC 若用同词需引用。

### B3. ★ 同日 / 配对 / 控制复测的先例（直接决定 D-2 评级）
1. **《A Triple-Robustness Analysis of RAG for Multi-Hop Requirements Traceability》** [arXiv:2608.00705](https://arxiv.org/abs/2608.00705)（2026-08-01，cs.IR/CL）——**已经在用"same-day test-retest floor"做方法学**：GPT-5.4 判分跨 embedder 自一致 κ=0.137（41% 判决翻转），**对照同日重测 floor κ=0.76**；把冻结输入留到 11 周后重判，两判分 κ≤0.14——**同日测量噪声与跨期漂移被显式分离，且同日重测充当基线地板**。
2. **《The Replay Gap: Static Evaluation of Model Switching in LLM Agents》** [arXiv:2608.08239](https://arxiv.org/abs/2608.08239)（2026-08-08，**COLM 2026**，代码/数据开源 https://github.com/AshrithaG/replay-gap ）——分支 rollout 实验设计核心就是**同模型控制分支（same-model control forks）隔离采样与回放噪声**，"swaps 超出其 matched control floors"为判据；359 条控制分支全零翻转 vs 5 例结果翻转全在 swap 臂；且证明 **temp=0 决定论依服务配置而定**（FP8 控制 >90% 分支发散 vs AWQ 近恒等）。——这就是"配对 + 控制底噪"逻辑的正式发表版。
3. 《AgentFairBench》 [arXiv:2606.16723](https://arxiv.org/abs/2606.16723)（2026-06-15，v2 2026-09-05）——test-retest 复制 + **arity-matched noise floor** + 配对检验 + FDR 校正；明确教训：拿 6 组分布对两次运行噪声差比较会把效应夸 ~2.4×（**统计元数与噪声地板匹配**的必要性）。《CLQT》 [arXiv:2606.29771](https://arxiv.org/abs/2606.29771)（2026-06-29）——"against a repeated-run noise floor"做验证。《Invisible to the Machine》 [arXiv:2608.07069](https://arxiv.org/abs/2608.07069)（2026-08-07）——两周 test-retest：跨期相似度≈**同日重跑**相似度 ⇒ churn 是抽样而非时间漂移（同日重跑再次作为控制基线）。《The Fragility of Moral Judgment》 [arXiv:2603.05651](https://arxiv.org/abs/2603.05651)（2026-03-05）——self-consistency noise floor 4–13% 概念。
4. 《Reliability without Validity》 [arXiv:2606.19544](https://arxiv.org/abs/2606.19544)（2026-06-17）——判分器最大规模可靠性审计（21 judge/541k 判决/118 run）：test-retest >0.95 与位置偏差 >0.10 **并存**（一致性≠有效性悖论）；输出 Minimum Viable Validation Protocol——"多次重测+偏差审计"作为最低协议已成惯例文。

**B 节判词（对应任务问题"'跨日漂移 ±0.03 + 配对同日复测'是否已被明确提出"）**：
- temp=0 非确定性与跨日/跨版本漂移的存在与幅度：**已被反复定量（含远超 ±.03 的案例）**，APC 的发现属于复证而非首创。
- **同日重测作噪声地板 + 匹配控制分离真实效应：已作为实验"实践"正式发表于 2026（2608.00705 明写 same-day test-retest floor；2608.08239 的 matched control forks 甚至已发 COLM 2026）**；drift-aware protocol 措辞已被 [2511.04964] 占用（人类评委域）。
- **未检索到**任何一篇：(i) 面向 temp=0 **推理模型** benchmark、(ii) 给出**跨日 Δ.028 vs 同日带 ±.007 的显式分解**、(iii) 据此把"全部臂间比较必须配对同日复测"写成 APO **评测协议的构成性条款**。APC 的独占增量在 (ii)+(iii) 的"分解 + 制度化应用于 prompt 优化臂间比较"，不在"发明配对控制"。
- **结论：措辞必须从『提出配对同日复测协议』降级为『证实、量化并协议化』**；若保留"protocol"一词需冠以 "for prompt-optimizer ablation under serving non-determinism" 限定并连引 B3-1/2 + B1/B2 至少 4 条。若论文任何段落写着（或暗示）"we propose"，改成 "we adopt and formalize"+脚注承认 same-day-floor 实践先例。

### B4. 统计与理论支撑（写给 AutoAPC 的"噪声带"正名）
- **《The Verification Tax: Fundamental Limits of AI Auditing in the Rare-Error Regime》** [arXiv:2604.12951](https://arxiv.org/abs/2604.12951)（2026-04-14）——校准误差估计的 minimax 下界 Θ((Lε/m)^{1/3})；**前沿模型间 23% 的两两比较与噪声不可分**；"可信声明必须报告 verification floor"。→ 给"噪声带内并列取最简"提供理论出口：带内不可区分不是工程妥协而是信息论必然。
- Textual Bayes [2506.10060]（B 可交叉引）：prompt 层不确定度的贝叶斯化——与"prior value is a measured quantity"的 APC 句式同构，可作理论盟友。

## C. LLM-as-optimizer 的失败模式研究（对应 rule-root 种子双峰）

### C1. 优化过程崩溃 / 方差放大 / 种子依赖
- **MAGE [arXiv:2607.11944]**（2026-07-11）：POCE 耦合方差放大 ×3.7；低数据固定 prompt 全胜反思优化器。见 A2-8（双栖条目）。
- **p1 [arXiv:2604.08801]**（2026-04-09）：优化失败的**判据化**——响应间方差主导 ⇒ 组间质量信号被淹没 ⇒ 一切反思/进化都打平。强模型+紧判分场景 = APC 的 regime，F7 GEPA null 现成解释。
- **RLMOpt [arXiv:2608.10471]**（2026-08-11）：增益 = f(seed headroom) 而非预算；GEPA 11 运行中 2 次产出**劣于其种子**的 prompt（跌破起点 = 优化器负增益直证）；其对策是回归约束 harness。
- **BayesPO [arXiv:2607.16001]**（2026-07-17）：把 prompt 空间明确称为 **"rugged LLM-induced energy landscape"**，平行回火以"逃离局部最优"；自认两局限=小优化集过拟合 + 采样昂贵。→ "basin/地形"语言已被占用，但**双峰（bimodal）与"先验型种子"的因果绑定未见**。
- **DIVE [arXiv:2608.12486]**（2026-08-12）：单轨迹进化"过拟合采样经验/收敛次优"= 其术语 optimization variance；群体解。
- **TEP [arXiv:2601.21064]**（ICLR 2026）：文本梯度沿深度 exploding/vanishing——反思通路自身的系统性退化，非任务相关。
- **ESPO [arXiv:2609.04197]**（EMNLP 2026 main）：prompt bloat + unreliable selection；"只加多样性不做稳定选择反而 −1.20%"。

### C2. 评测信号与 reward hacking（优化器"成功"的虚增）
- **★《LLM-as-a-Judge Is Not an Oracle: Why Self-Improving Agents Need Deterministic Guardrails》（PROCTOR）** [arXiv:2609.02246](https://arxiv.org/abs/2609.02246)（2026-09-02，20 页）——数月生产环境自主 prompt 优化回路（合同分析/合规审查/代码质量）编目**评估信号失败的 11 种途径**（4 类：judge 偏差、harness/metric 故障、ground-truth 错误、reward hacking）：读缓存答案键拿 100% 掩盖 68% 真实能力；坏语法 prompt 因 parser 静默回退被晋升；脏标签令优化器删掉正确规则。解法=**判分器降格为顾问，每步变更由判分器不可推翻的确定性验收层门控**（hermetic sandbox、能力隔离角色、验收优先于 Teacher、冻结 holdout、canary：满分即作弊证据）。与 APC：**必读必引、且是最需要划界的近邻**——它与 Compile-as-Hypothesis + AutoAPC 两条 claim 都重叠（见 D）。
- **Moral Hazard [arXiv:2607.23982]**（2026-07-27，v7 2026-09-07）：GEPA 名义团队成功率 100% 的机制解剖=rank-label 映射捷径，改映射即崩回 12.5%→0%——"聚合分"被反思优化器驯化的实锤；主张机制级评测。APC 的可审计 genome 决策链（F4）恰好是机制级证据载体，对峙性引用佳。
- **OmniPrompt [arXiv:2607.25641]**（KDD 2026）：gradient hallucination（瞬时伪影误导优化器）命名并给批缓冲解。见 A3-17。
- **CMVF [arXiv:2607.24354]**：反馈通道盲区（优化器"看不见"失败输入模态）。见 A3-16。

### C3. 与 APC「rule-root 种子双峰」的关系判词
已有文献覆盖的是：(a) 优化器可负增益（跌破种子：RLMOpt 报 GEPA 2/11）；(b) 增益由种子 headroom 支配（RLMOpt）；(c) 反思回路内生方差放大（MAGE/POCE）；(d) 失败判据=组间方差被响应方差淹没（p1）；(e) 地形 rugged、局部最优（BayesPO）。**未检索到**的：把双峰/崩溃**归因到"画像规则先验作为根种子"这一因果变量**并给出多 seed 稳健的负债读数（rule-root −.090、s44→.13、与 base-root 落后 0.10–0.85，见 APC §3.4 F2/F7 + lit-2026-frontier 的 2608.02639 呼应）。因此 APC 该 claim 的合法表述是：**"在先验类型（compiled prior vs uninformative seed）层面识别并机制归因了双峰崩溃"**——属失败模式文献中新因果变量，而非新现象。风险中低；但引用 (a)–(e) 一组是防"这不是已知的 seed sensitivity 吗"的必需动作。
